# 触摸屏引脚记录

- 屏幕类型：**电阻屏**（XPT2046 / TSC2046 / ADS7843 系列，SPI 软模拟）
- 来源：F407VE 核心板「触摸屏例程」`HARDWARE/TOUCH/touch.h`
- 实物排针阵列图与接线映射为粘贴内容，信息准确，未作更改

## 引脚定义

| 信号 | 宏 | MCU 引脚 | 方向 |
|------|-----|---------|------|
| T_PEN（笔按下检测） | `PEN` | PC5 | 输入 |
| T_MISO（数据输出） | `DOUT` | PB14 | 输入 |
| T_MOSI（数据输入） | `TDIN` | PB15 | 输出 |
| T_SCK（时钟） | `TCLK` | PB13 | 输出 |
| T_CS（片选） | `TCS` | PB12 | 输出 |

## LCD FSMC 接口（20 根）

| 功能 | 信号 | MCU 引脚 |
|------|------|---------|
| 片选 CS | FSMC_NE1 | PD7 |
| 命令/数据 RS | FSMC_A18 | PD13 |
| 写 WR | FSMC_NWE | PD5 |
| 读 RD | FSMC_NOE | PD4 |

数据线 D0~D15：

| 线 | 引脚 | 线 | 引脚 |
|----|------|----|------|
| D0 | PD14 | D8 | PE11 |
| D1 | PD15 | D9 | PE12 |
| D2 | PD0 | D10 | PE13 |
| D3 | PD1 | D11 | PE14 |
| D4 | PE7 | D12 | PE15 |
| D5 | PE8 | D13 | PD8 |
| D6 | PE9 | D14 | PD9 |
| D7 | PE10 | D15 | PD10 |

## 电源 / 背光 / 复位

| 功能 | 信号 | 引脚/定义 | 说明 |
|------|------|----------|------|
| 系统电源 | 5V → AMS1117-3.3V → 3V3 | 板上供电 | LCD 模块供电 3V3 / GND |
| LCD 背光 | `LCD_LED` = `PBout(1)` | **PB1** ⚠️存疑 | lcd.h:80 定义为 PB1，但需实物验证 |
| LCD 复位 | `LCD_RESET#` | **系统 RST（NRST）** | 无独立 GPIO，直连板上复位 |

## 物理排针阵列图（实物粘贴）

### 1. 蓝色 LCD 屏幕模块（底端排针物理阵列图）

这是屏幕背面底部 双排 17×2 排针 的物理布局（丝印在排针左侧和中间）：

```
                 【 蓝色 LCD 屏幕背面排针矩阵 】
                 (视角：背面对着自己)

                (左列 / 外侧)             (右列 / 内侧)
              +-----------------------+-----------------------+
              | T_CS  (触摸片选)      | CLK   (触摸SPI时钟)   |
              | PEN   (触摸中断)      | F_CS  (Flash片选/空)  |
              | MISO  (触摸数据输出)  | MOSI  (触摸数据输入)  |
              | GND   (电源地)        | NC    (无连接)        |
              | VDD   (电源正)        | GND   (电源地)        |
              | BL    (背光控制)      | VDD   (电源正)        |
              | DB15  (数据线15)      | SDCS  (SD卡片选)      |
              | DB13  (数据线13)      | DB14  (数据线14)      |
              | DB11  (数据线11)      | DB12  (数据线12)      |
              | DB9   (数据线9)       | DB10  (数据线10)      |
              | DB7   (数据线7)       | DB8   (数据线8)       |
              | DB5   (数据线5)       | DB6   (数据线6)       |
              | DB3   (数据线3)       | DB4   (数据线4)       |
              | DB1   (数据线1)       | DB2   (数据线2)       |
              | RST   (屏复位)        | DB0   (数据线0)       |
              | WR    (写使能)        | RD    (读使能)        |
              | CS    (片选)          | RS    (命令/数据选择) |
              +-----------------------+-----------------------+
                                 | | (引脚朝下)
```

注解：8080 LCD 接口：底部的 CS, RS, WR, RD, RST 和 DB0~DB15。SPI 接口：顶部的 T_CS, PEN, MISO, MOSI, CLK（给触摸芯片）以及 SDCS（给 SD 卡）。

### 2. 黑色 DeveBox 开发板（New-TFT 母座物理阵列图）

这是黑板右侧 双排 17×2 母座 上的实际丝印布局：

```
                 【 黑色 DeveBox 开发板母座矩阵 】
                    (视角：主板正面/丝印朝上)

                (左列 / 靠内侧)           (右列 / 靠边缘)
              +-----------------------+-----------------------+
              | 3V3   (电源 3.3V)     | 3V3   (电源 3.3V)     |
              | GND   (电源地)        | GND   (电源地)        |
              | TIRQ  (触摸中断)      | BLK   (背光控制)      |
              | TSI   (触摸数据输入)  | TSO   (触摸数据输出)  |
              | TSCK  (触摸SPI时钟)   | TCS   (触摸片选)      |
              | RS    (命令/数据选择) | CS    (片选)          |
              | RD    (读使能)        | WE    (写使能)        |
              | D01   (数据线1)       | D00   (数据线0)       |
              | D03   (数据线3)       | D02   (数据线2)       |
              | D05   (数据线5)       | D04   (数据线4)       |
              | D07   (数据线7)       | D06   (数据线6)       |
              | D09   (数据线9)       | D08   (数据线8)       |
              | D11   (数据线11)      | D10   (数据线10)      |
              | D13   (数据线13)      | D12   (数据线12)      |
              | D15   (数据线15)      | D14   (数据线14)      |
              | RST   (屏复位)        | GND   (电源地)        |
              | 1     (方焊盘标志脚)  | [未标注]              |
              +-----------------------+-----------------------+
```

注解：黑板把电源放在了最顶端（3V3/GND），而蓝屏的电源在中间；黑板的 WE 就是写使能，对应蓝屏上的 WR；黑板的 TSI/TSO 对应蓝屏的 MOSI/MISO。

## 说明

- 触摸芯片通过这 5 根引脚以 SPI（软件模拟）方式通信。
- LCD 本身仍走 FSMC 接口（NE1=PD7、A18=PD13、RD=PD4、WR=PD5、D0~D15）。
- 当前使用的是电阻屏，因此**电容屏（GT9147/OTT2001A）那组 IIC 引脚（PB0/PF11、PC13、PB1）不适用**。
