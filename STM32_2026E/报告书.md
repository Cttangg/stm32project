## 0. 结论摘要

现有工程是**红色激光云台 2 轴闭环骨架**，其驱动层（`uart` / `mt6701` / `tmc2209` / `motor_stepper`）设计良好、可复用；但距离任务书要求的 **XYZ 三轴 + 取放机构 + 安全体系** 存在硬缺口：

- **R1 阻断**：当前只有 X/Y 两轴（TIM13/TIM14），**无 Z 轴、无取放机构**。
- **R2 阻断**：**无急停、无限位、无驱动器故障检测**。
- **R3 高**：编码器读取为**阻塞 I2C**（超时 50ms），违反非阻塞约束。
- **R5 高**：无看门狗，跑飞/断联不可恢复。
- **R6 中**：PID 误差按角度卷绕（±180°），直线轴必须修改。

在硬件信息齐备前，运动与安全相关代码不编写。

## 1. 现状核查（任务书 §2 十项）

### 1.1 MCU / 时钟 / HAL
- **型号**：STM32F407VET6，Cortex-M4，LQFP100（`.ioc:57,71-72`）；CubeMX 6.18.1，固件包 FW_F4 V1.28.3（`.ioc:117,274`）。
- **时钟**：HSE 8MHz → PLL(M=4,N=168,P=2,Q=4) → SYSCLK 168MHz；AHB=168，APB1=42（定时器 84MHz），APB2=84（定时器 168MHz）（`Core/Src/main.c:209-248`，`.ioc:297-329`）。
- **HAL/LL**：用户代码**只用 HAL**，未调用 LL。启用模块：I2C / SPI / TIM / UART / GPIO / EXTI / DMA / RCC / FLASH / PWR / CORTEX（`Core/Inc/stm32f4xx_hal_conf.h:38-90`）。

### 1.2 是否 FreeRTOS / 任务与中断结构
- **无 RTOS**：`USE_RTOS 0U`（`stm32f4xx_hal_conf.h:152`）。裸机超级循环 `while(1)`（`Core/Src/main.c:186`）。
- **无任务**。中断向量：SysTick、DMA1_S5/S6、DMA2_S2/S7、USART1/2、I2C1/2 EV+ER、TIM8_UP_TIM13、TIM8_TRG_COM_TIM14（`.ioc:119-141`）。
- **优先级问题**：所有外设 IRQ 优先级均为 `0,0`（`main.c:524-534`、`stm32f4xx_hal_msp.c:116-148,297-312,426-491`），分组 `NVIC_PRIORITYGROUP_4`（`.ioc:134`），SysTick=15。**即所有外设中断同级、无抢占层次**。

### 1.3 电机驱动类型 / 接口 / 脉冲 / 使能
- **TMC2209 ×2**，纯 GPIO 控制（EN/DIR/STEP/MS1/MS2），**不使用其 UART 寄存器配置**（`Core/Lib/tmc2209.c:26-81`）。
- **STEP 由 TIM13/TIM14 更新中断翻转 GPIO 产生**，非阻塞；更新率 = 2×步率；软上限 50000 steps/s；定时器时钟 84MHz（`Core/Lib/motor_stepper.c:16,35,38-54,120-136`）。
- 使能**低有效**（`tmc2209.c:41-49`）；默认 1/32 细分（MS1=H, MS2=L，`tmc2209.c:31,37-38`）。
- **只有 2 轴**（TIM13/TIM14）→ **任务书要求的 Z 轴不存在**。

### 1.4 编码器 / 位置反馈来源与单位
- **MT6701 ×2**，I2C1/I2C2，400kHz，14-bit，地址 0x06（`Core/Lib/mt6701.h:28,44`，`main.c:145-150`）。
- 反馈单位 = **角度 deg**（`MT6701_ReadDegrees`），多圈靠软件计数（`mt6701.c:130-148`）。
- **编码器在旋转轴上，非直线光栅**；直线位置需换算，且皮带/丝杠弹性与背隙会使"电机角" ≠ "滑台真实位置"。

### 1.5 限位 / 急停 / 驱动器故障
- **全部缺失**：无限位开关、无急停输入、无 TMC DIAG/INDEX 接线。
- 现有可复用输入：6 个按键 GPIO `PB3/PB5/PB8/PB9/PE0/PE1`（`Core/Inc/main.h:88-99`），`NOPULL` 输入（`main.c:601-611`）。

### 1.6 取放机构
- **完全缺失**：无任何输出/接口分配，机构类型未知。列入待确认，不编造。

### 1.7 通信 / DMA / 中断
- USART1 调试口 PA9/PA10，USART2 摄像头 PA2/PA3，均 115200-8N1（`main.c:451-510`）。
- DMA：USART1_RX=DMA2_S2、TX=DMA2_S7；USART2_RX=DMA1_S5、TX=DMA1_S6。**RX 全部 CIRCULAR，TX 全部 NORMAL**（`.ioc:15,25,35,45`，`stm32f4xx_hal_msp.c:397,415,461,479`）。
- 接收机制：DMA CIRCULAR + IDLE/HT/TC 事件 → 软件环形 → 帧解析链表（`Core/Lib/uart.c:258-291`，`uart.h:76-92`）。
- **无 CAN、无 USB**。

### 1.8 阻塞点清单
详见 §3。

### 1.9 直接控制电机的入口
详见 §4。

### 1.10 构建 / 下载 / 运行 / 测试
- 构建：CMake Presets（Debug/Release）+ Ninja + `cmake/gcc-arm-none-eabi.cmake`：
  ```
  cmake --preset Debug
  ```

## 3. 现有阻塞点 / 长延时 / 等待循环 / 潜在死锁

| 位置 | 类型 | 影响 | 严重度 |
|------|------|------|--------|
| `mt6701.c:85-96` | `HAL_Delay()` ×~14（≈21ms） | I2C 总线恢复，仅 `MT6701_Init` 调用 | 中（仅初始化） |
| `mt6701.c:23,31,40` | `HAL_I2C_Mem_Read/Write` 超时 **50ms** | **读角度路径上的阻塞调用**；总线卡死可阻塞 50ms | **高**（违反非阻塞） |
| `mt6701.c:105` | `HAL_I2C_IsDeviceReady` 超时 10ms | 仅 Init | 低 |
| `uart.c:230` | `while (rb_read(...))` | 受环形缓冲上限约束（≤1024B），非真阻塞，但单次可能处理较久 | 低 |
| `main.c:630-631` | `Error_Handler` 关全局中断 + `while(1)` | 任何 HAL init 失败 → 静默死机，无看门狗、无上报 | **高**（无恢复） |
| `stm32f4xx_it.c:85-148` | 故障 handler `while(1)` | HardFault 等直接停机 | 中 |
| 全局 | 无 IWDG（`HAL_IWDG` 未启用） | 跑飞/通信丢失无法自恢复 | **高** |
| 全局 | 无 `while(!motion_done)`、无控制回路 `HAL_Delay` | 目前无同步等待式运动 | — |

**未发现明显状态机死锁**（`uart.c` 帧超时复位正常，`motor_stepper` 纯 ISR 无锁）。

## 4. 电机与取放机构接口分析

### 4.1 现有电机控制入口（全部在 BSP/驱动层，应用层尚未调用）
1. `TMC2209_Enable/Disable/SetDirection/SetMicrostep`（`tmc2209.c:41-81`）— GPIO 写。
2. `MotorStepper_SetVelocity / MoveSteps / Stop`（`motor_stepper.c:78-111`）— 速度/位移，非阻塞。
3. `MotorStepper_IRQHandler`（`motor_stepper.c:120`）— 由 `stm32f4xx_it.c:329,343` 分发，直接翻转 STEP 引脚。
4. 闭环链路（**当前仅在注释中**）：`enc → MotorPID_Update → pid.vel_ref → MotorStepper_SetVelocity`（`main.c:192-196`）。

**问题**：以上入口目前**无统一门禁**，任何调用者都能直接驱动轴；应用层若直接调用即违反"Motion Manager 唯一入口"约束。

### 4.2 取放机构
无接口、无引脚、无类型信息 → **无法设计抽象**，必须由总设计师提供硬件定义。

## 7. 风险清单

| # | 风险 | 级别 | 说明 |
|---|------|------|------|
| R1 | **硬件与需求不符**：需求 XYZ+取放机构，现工程仅 XY 两轴、无 Z、无机构 | 阻断 | 阶段 B 起无法实现 |
| R2 | **无急停/限位/驱动器故障硬件** | 阻断 | 安全要求无法满足 |
| R3 | 编码器 I2C 读为阻塞调用（50ms 超时） | 高 | 违反非阻塞；需异步化或状态机化 |
| R4 | 所有外设 IRQ 同级（prio 0） | 高 | 运动 ISR 与通信 ISR 无法分级，抖动/丢帧风险 |
| R5 | 无 IWDG | 高 | 跑飞/断联不可恢复 |
| R6 | PID `wrap180` 为角度专用（`motor_pid.c:16-20,89,104`） | 中 | 直线轴会错误卷绕，必须改 |
| R7 | 编码器在电机轴，非直线反馈 | 中 | 皮带弹性/背隙使定位非真值；需标定或改直线反馈 |
| R8 | 未做 Bootloader 迁移 | 中 | 烧录流程与其它工程不一致 |
| R9 | 本机缺 `gnu-tools-for-stm32` | 中 | 无法编译验证，所有结论只能静态分析 |
| R10 | ST7735 仅骨架 | 低 | 若需 UI 需额外工作量 |
| R11 | README 与实际配置漂移 | 低 | 误导后续维护 |
| R12 | 无测试框架 | 中 | 任务书 §7 测试要求需先搭测试基础设施 |

## 9. 待确认清单（不得编造，请总设计师提供）

1. **Z 轴**：电机型号/驱动器/TIM 资源/脉冲与使能引脚/是否有失电制动？
2. **取放机构**：类型（电磁铁/气动/舵机/电动夹爪）、控制接口、反馈（开合到位/工件检测）、电源。
3. **限位**：每轴几个、常开/常闭、有效电平、接哪些引脚（可否复用 6 个按键输入）？
4. **急停**：硬件链路（是否切断驱动器使能/电机电源）、有效电平、是否需 MCU 检测。
5. **驱动器故障**：TMC2209 DIAG/INDEX 是否接线、有效电平。
6. **机械参数**：`steps/mm`、各轴行程、最大速度/加速度、回零方向与顺序。
7. **编码器方案**：确认装电机轴还是直线；是否需要直线尺。
8. **摄像头协议**：帧格式/校验/序号，输出是像素还是已换算坐标；坐标变换由谁做。
9. **上位机通信**：USART2 还是改用其它总线；协议版本与心跳。
10. **Bootloader**：是否需要按 AGENTS 迁移到 `0x08008000` 软 Bootloader 流程。
11. **RTOS**：确认继续裸机超级循环，还是引入 FreeRTOS（影响非阻塞架构）。
12. **工具链**：请安装 `gnu-tools-for-stm32` 或告知编译器路径，否则无法执行编译验证。
