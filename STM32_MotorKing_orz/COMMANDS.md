# 调试命令与参数手册 (COMMANDS)

> 适用：`STM32_MotorKing_orz`（红色激光云台）
> 串口：**USART1** 调试口，`115200-8-N-1`，命令以 `\r`（或 `\n`）结尾。

---

## 1. 按键

| 按键 | 引脚 | 功能 |
|---|---|---|
| KEY_PAUSE | PB3 | 暂停/继续：立即制动，再按恢复（Q1/Q2 测量光斑用） |
| KEY_RESET | PB5 | 复位：自动运动到 **O** 点后保持；同时清除轴故障 |
| KEY_BORDER | PB9 | 沿边框：左上起**顺时针** 左上→右上→右下→左下→左上→O，完毕保持 |
| KEY_CALIB | PE0 | 标定：第 1 按释放电机，之后每按一次记录一个点（见 §4） |
| KEY_TRACK / KEY_A4 | PB8 / PE1 | 预留，暂未实现 |

---

## 2. 运动与测试命令

| 命令 | 说明 |
|---|---|
| `go <pan> <tilt>` | 双轴运动到绝对角度(deg)；经 Motion 限幅 → Axis 闭环 |
| `stop` | 停止并保持当前位置 |
| `pos` | 打印两轴当前角度与 PID 目标 |
| `stat` | 打印两轴 PID 内部状态（target/current/vel_ref/state） |
| `swing <amp>` | Tilt 以当前位置为原点 ±amp(deg) 往复摆动 |
| `swing stop` | 停止摆动，回到原点 |
| `spin` | Tilt 开环走整圈(6400 步)，每 100ms 采样编码器，验证回正 |
| `fault` | 打印上次 HardFault 现场（诊断） |
| `echo` | 回显最近一条命令 |
| `boot` | 跳回 Bootloader（当前为直烧模式，一般不用） |

### PID 状态码（`stat` 的 `st`）

| 值 | 状态 |
|---|---|
| 0 | DISABLED |
| 1 | MOVING |
| 2 | APPROACHING |
| 3 | HOLDING（到位锁定） |

## 3. 在线调参命令（按轴）

**轴选择**：`x` = Pan（水平轴），`y` = Tilt（竖直轴）。（也接受 `p`/`t`。）

| 命令 | 说明 |
|---|---|
| `gains <x\|y> <kp> <ki> <kd>` | 设置位置环增益 |
| `limit <x\|y> <max_speed> <max_accel>` | 速度/加速度上限（**控制走步快慢**） |
| `dead <x\|y> <enter> <exit> <comp_max> <stiction>` | 死区与静摩擦补偿 |
| `lp <x\|y> <d_alpha>` | D 项低通系数（0~1） |
| `params <x\|y>` | **回读**该轴全部可调参数 |
| `pid <kp> <ki> <kd>` | 便捷命令，等价于 `gains x …`（X 轴快捷） |

> 所有参数**立即生效**（PID 每周期读取这些字段），但**不持久化**，复位/断电后回到编译默认值。

### 3.1 参数含义与单位

| 参数 | 单位 | 含义 |
|---|---|---|
| `kp` | (steps/s)/deg | 位置误差 → 速度的比例增益 |
| `ki` | (steps/s)/(deg·s) | 积分增益（消稳态误差） |
| `kd` | steps/deg | 微分增益（D 作用在测量速度上，提供阻尼） |
| `d_alpha` | 0~1 | 测量速度低通系数，越大越平滑 |
| `max_speed` | steps/s | 速度上限（**越小走步越慢**） |
| `max_accel` | steps/s² | 加速度上限（越小启停越柔和） |
| `enter` | deg | 进入 HOLDING 的死区阈值 |
| `exit` | deg | 退出 HOLDING 的阈值（需 ≥ enter，滞回） |
| `comp_max` | deg | 静摩擦补偿窗口上界 |
| `stiction` | steps/s | 静摩擦补偿最小速度（推过摩擦死区） |

### 3.2 步数/角度换算（1/32 细分）

```
STEPS_PER_REV = 6400 步/圈      STEPS_PER_DEG = 17.78 步/deg
速度:  deg/s = steps/s ÷ 17.78
例:    19200 steps/s ≈ 1080 °/s ;  4000 steps/s ≈ 225 °/s ;  3000 ≈ 169 °/s
```

### 3.3 编译默认值

| 参数 | Pan(X) | Tilt(Y) | 默认(MotorPID_Init) |
|---|---|---|---|
| kp | 350 | 1500 | 1500 |
| ki | 30 | 100 | 100 |
| kd | 0 | 125 | 125 |
| d_alpha | 0.8 | 0.8 | 0.8 |
| max_speed | 7200 | 19200 | 19200 |
| max_accel | 36000 | 96000 | 96000 |
| dead enter/exit | 0.05 / 0.5 | 0.05 / 0.5 | 0.05 / 0.5 |
| comp_max | 0.5 | 0.5 | 0.5 |
| stiction | 150 | 150 | 150 |

## 4. 标定点与 Q1/Q2 序列

### 标定（KEY_CALIB，共按 6 次）
1. 第 1 次：**释放两轴电机**（可手动扳动云台），进入标定；
2. 第 2~6 次：依次记录当前角度到 **O → 左上 → 右上 → 右下 → 左下**；
3. 记录满 5 点自动**重新锁定**电机。

每次按下会向串口打印 `CAL pt=<n> pan=.. tilt=..`；读失败打印 `CAL read fail, retry`（不记录）。

### 命令操作

| 命令 | 说明 |
|---|---|
| `pts` | 打印 5 点（`*` 表示已标定） |
| `cal <id>` | 把**当前角度**记到点 `id`（0=O 1=左上 2=右上 3=右下 4=左下） |
| `goto <id>` | 运动到已标定点 |

### 序列（也可用按键触发）
- **复位**：`KEY_RESET` → 运动到 O 后保持 idle。
- **沿边框**：`KEY_BORDER` → 左上起顺时针（含闭合左边）一周后回 O 保持 idle。
- 采用"到位判定 + 推进"：两轴 `in_position` 持续 `settle_ms` 后自动下一点；单点超 `point_timeout_ms` 强制推进。

## 5. 典型调参流程

### (a) 走步太快 → 降速
```
params x            # 先看当前 vmax/amax
limit x 4000 40000  # X 轴限速 ≈225°/s
limit y 4000 40000  # Y 轴同上
```
觉得还快就继续降 `max_speed`（如 2500~3000），`max_accel` 一起降会更柔和。

### (b) X 轴在线整定
```
params x            # 回读当前参数
gains x 700 100 0   # 先设一组起点
# 观察目标附近是否震荡 / 是否追到位:
gains x 500 80 150  # 例: 降 kp 抑振荡, 加 kd 增阻尼
params x            # 每步回读确认
```
整定顺序建议：先调 `kd`（消振荡）→ 再调 `kp`（控过冲）→ 最后 `ki`（消稳态误差）。

### (c) 单点细调示例
```
go 120 30           # 移动到某角度
# 若停不下来有微动:
dead x 0.10 0.60 0.60 200
```

---

## 6. 注意事项

- 在线参数**掉电不保存**；确定好的值请写回 `motor_pid.c` / `main.c` 的初始化。
- `limit` 是全局影响该轴所有运动（含序列、视觉外环），不只是测试命令。
- `stop`/暂停恢复的目标由 Motion 管理；暂停期间 Q12 序列冻结，恢复时重发当前点。
- `cal`/`goto`/`pts` 作用于标定点（角度空间）；`goto` 需求点已标定，否则返回 `GOTO-FMT/INVALID`。
